# Build a Static Site Generator in Python

A guided project from [Boot.dev](https://www.boot.dev/courses/build-static-site-generator-python) that teaches you to build a static site generator from scratch, similar to Jekyll, Hugo, or Gatsby.

## About This Course

**Author:** Lane Wagner  
**Duration:** ~30 hours  
**Lessons:** 28  
**Rating:** 4.6/5 (896 reviews)

Learn how SEO and performance-optimized static site generators work by building your own from scratch using Python. This project puts your Object-Oriented Programming and Functional Programming skills into practice in a tangible web project.

## What You'll Build

A complete static site generator that:
- Processes and moves static HTML and Markdown files
- Uses recursion and OOP for HTML generation
- Parses inline Markdown and generates inline HTML elements
- Handles entire blocks of Markdown and generates HTML nodes
- Publishes a complete static website

## Course Chapters

1. **Static Sites** - Learn about static sites, process HTML and Markdown files
2. **Nodes** - Build core HTML generation logic using recursion and OOP
3. **Inline** - Parse inline Markdown and generate inline HTML elements
4. **Blocks** - Handle blocks of Markdown and generate HTML nodes
5. **Website** - Assemble the complete static site generator and publish

## Skills You'll Gain

- Object-Oriented Programming
- Recursion
- Markdown parsing
- HTML generation
- Tree traversal algorithms
- Unit testing with Python's unittest module
- Static site architecture
